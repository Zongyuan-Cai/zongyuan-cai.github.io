## About · 关于我

I explore how language model agents can reason, use tools, and learn from experience. My interests include agent memory, self-evolution, and multimodal systems that turn scientific knowledge into understandable visual explanations.

我关注语言模型智能体如何推理、使用工具，并从经验中学习，尤其对智能体记忆、自进化，以及将科学知识转化为可理解的视觉表达感兴趣。

## Selected Research · 代表性研究

### [ManimAgent: Self-Evolving Multimodal Agents for Visual Education](https://arxiv.org/abs/2606.30296)

Wenjia Jiang, **Zongyuan Cai**, Yuanhang Shao, Chenru Wang, Boyan Han, Zhixue Song, Keyu Chen, Shengwei An, Xu Yang, Zhou Yang

**EMNLP 2026 · Poster** · [arXiv:2606.30296](https://arxiv.org/abs/2606.30296)

An agent that turns scientific content into Manim animations and retains useful examples and failure lessons in a dual-channel memory bank. Experience carries across tasks without updating model weights.

通过双通道记忆库积累成功案例与失败教训，让生成科学动画的智能体能够跨任务利用经验，无需更新模型权重。

[Paper](https://arxiv.org/abs/2606.30296) · [PDF](https://arxiv.org/pdf/2606.30296) · [Project Page](https://manimagent.github.io/) · [Code](https://github.com/jwj1342/Paper2Manim)

## 博客写作

博客地址：https://zongyuan-cai.github.io/blog/

在 `_posts` 文件夹新增 `YYYY-MM-DD-英文短标题.md`，例如 `2026-10-11-first-post.md`：

```markdown
---
title: "我的第一篇文章"
description: "文章的简短介绍。"
---

在这里写正文。

<!--more-->

## 小标题

继续写你的想法。
```

提交到 `main` 后，GitHub Pages 会自动生成文章列表、正文页和订阅源，通常几分钟后可见。文章标题可以用中文，文件名建议使用小写英文和短横线。日期不要晚于当天，未来日期的文章默认不会发布。

草稿可先放在 `_drafts`；这个文件夹不会生成网页，但公开仓库中的草稿源码仍能被查看。未准备公开的内容请保存在本地。

图片可以放在 `assets/images`，在文章里使用 `![图片说明](/assets/images/example.png)`。代码块、列表、引用、表格和 Markdown 链接都可直接使用。

修改博客简介：编辑 `_config.yml` 的 `description`。修改外观：编辑 `assets/css/blog.css`。

GitHub 官方说明：[添加文章](https://docs.github.com/en/pages/setting-up-a-github-pages-site-with-jekyll/adding-content-to-your-github-pages-site-using-jekyll)。
